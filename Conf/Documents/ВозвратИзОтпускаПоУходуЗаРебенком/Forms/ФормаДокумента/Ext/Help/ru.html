Возврат из отпуска по уходу

Документ предназначен для регистрации прекращения отпуска по уходу за ребенком, зарегистрированного ранее документом Отпуск по уходу за ребенком. Документ удобно вводить на основании прекращаемого отпуска.

Заполнение документа

Начиная с указанной даты возврата возобновятся его ранее действующие плановые начисления. При необходимости их можно изменить в этом документе.
