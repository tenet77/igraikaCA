Основное
  • Организация и Подразделение - организация и подразделение, в которые принимаются основные средства;
  • МОЛ - материально-ответственное лицо за основные средства;
  • Адрес - адрес, по которому числятся основные средства;
  • Направление деятельности - Направление деятельности, для которого используются активы. Расходы на приобретение основных средств тоже должны быть отнесены на выбранное направление деятельности. Если поле заполнено, то допускается выбирать основные средства, у которых указано аналогичное направление деятельности. Учет внеоборотных активов по направлениям деятельности может быть использован для расширенной детализации учета затрат в рамках проектного учета. В этом случае аналитика Направление деятельности соответствует управленческой аналитике для раздельного учета затрат по проектам, в рамках которых формируется стоимость внеоборотных активов и ведется учет иных затрат и доходов.

Основные средства

На закладке указывается список принимаемых к учету основных средств.

С помощью команды Заполнить - Подобрать можно добавить несколько основных средств. Для быстрого заполнения списка группой однотипных основных средств необходимо в форме выбора отобрать основные средства по наименованию, выделить несколько строк списка и добавить их в документ с помощью команды Выбрать.

Параметры учета


Бухгалтерский учет:

  • Способ начисления амортизации - доступны следующие способы: Линейный, Пропорционально объему продукции (работ), Уменьшаемого остатка, По сумме чисел лет срока;
  • Срок использования - срок полезного использования в месяцах;
  • Коэффициент ускорения - поле доступно, если используется способ начисления Уменьшаемого остатка.


Налоговый учет:

  • Порядок учета - доступны следующие варианты учета: Начисление амортизации, Двойная норма амортизации, Преференция: единовременное отнесение на вычеты, Преференция: отнесение на вычеты равными долями в течение 3-х лет, Стоимость не погашается (не является фиксированным активом) .

Отражение расходов

На закладке указываются параметры отражения расходов при начислении амортизации и начислении местных налогов.

Флаг Передавать расходы в другую организацию устанавливается, если необходимо передавать расходы по амортизации в головную организацию или обособленное подразделение. При этом требуется указать организацию-получателя расходов.

Способ отражения расходов можно изменить с помощью документа Изменение параметров ОС.
