Форма отчета7012020 кв1

Отчет предназначен для составления отчетности по транспортному налогу.

Необходимость начисления текущих платежей по налогам определяется в карточке организации на закладке "Учетная политика и налоги" по гиперссылке "Порядок уплаты авансов по налогам" для каждого вида налога отдельно.

Приложение заполняется по всем основным средствам, являющимся объектами обложения налогом на транспорт по состоянию на 1 июля отчетного года. Информация об обложении транспортного средства налогом устанавливается документом "Регистрация транспортных средств". Перед заполнением отчета требуется выполнение операций закрытия периода.

При наличии в структуре предприятия территориально удаленных обособленных подразделений, уплата налогов по которым производится по месту нахождения, в карточке организации таких подразделений требуется установить признак "Относить налоги к бюджету городов районного значения, сел, поселков, сельских округов" на закладке Учетная политика и налоги.

При формировании отчета в него будут заполнены данные по транспортным средствам выбранной организации, а также по транспортным средствам подразделений с отдельной регистрацией в налоговом органе у которых заполнено значение Аппарата акима.
