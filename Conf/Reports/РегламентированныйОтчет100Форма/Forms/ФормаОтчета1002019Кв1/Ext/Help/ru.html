Отчет «Декларация по корпоративному подоходному налогу, форма 100.00 (XML)» за 2018 год

Отчет «Декларация по корпоративному подоходному налогу» предназначен для составления отчетности по КПН.

 

Работа с расшифровкой строк регламентированного отчета.

Расшифровка строк возможна для тех ячеек, которые выделены голубым цветом.

 

При заполнении формы 100.00 учитываются данные не только из заполненных приложений, но и непосредственно данные, отнесенные на статьи расходов или доходов, для которых определен код строки Декларации в регистре сведений «Коды строк декларации по налогу на прибыль», начинающийся с «100.00». При заполнении строк декларации следует исходить из того, что если в конфигурации не автоматизировано заполнение нужного приложения, то необходимо для статьи расхода или дохода в регистре «Коды строк декларации по налогу на прибыль» проставить код строки, начинающийся с «100.00», а не код приложения, заполнение которого не предусмотрено. Если необходимого кода строки нет в классификаторе, то его нужно установить «вручную».

При указании кодов строк декларации по КПН нужно указывать коды строк непосредственно для организации плательщика КПН (головной организации), либо не указывать организацию вовсе.

1. Указывается стоимость поступивших в течение налогового периода запасов, в том числе приобретенных, полученных безвозмездно, в результате реорганизации путем присоединения, полученных в качестве вклада в уставный капитал, а также поступивших по иным основаниям;

К таким услугам можно отнести те затраты, которые, согласно МСФО №2 и требованиям бухгалтерского законодательства РК, должны включаться в себестоимость запасов (например, затраты на приобретение и прочие затраты, понесенные для того, чтобы обеспечить текущее местонахождение и состояние запасов).
