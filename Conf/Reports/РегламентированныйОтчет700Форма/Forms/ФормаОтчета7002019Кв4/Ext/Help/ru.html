Форма отчета7002019 кв4

Необходимость начисления текущих платежей по налогам определяется в карточке организации на закладке Учетная политика и налоги по гиперссылке Порядок уплаты авансов по налогам для каждого вида налога отдельно.

При расчете данных по налогу на имущество база объектов исчисления определяется по всем основным средствам и нематериальным активам, являющимся объектами обложения налогом на имущество в течение отчетного периода. Информация об обложении имущественным налогом устанавливается документом Регистрация порядка налогообложения по налогу на имущество.

Перед заполнением отчета требуется выполнение операций закрытия периода.

ЗАПОЛНЕНИЕ ПРИЛОЖЕНИЯ 700.01.

При составлении формы 700.01 по городам районного значения, селам, поселкам, сельским округам, являющимся местом нахождения юридического лица, его структурного подразделения налогоплательщиком составляется отдельное приложение к декларации по каждому городу районного значения, селу, поселку, сельскому округу. Для автоматического распределения объектов транспортного налога между аппаратами акимов, в карточке организации таких подразделений требуется установить признак Относить налоги к бюджету городов районного значения, сел, поселков, сельских округов на закладке Учетная политика и налоги.
При формировании отчета в него будут заполнены данные по транспортным средствам выбранной организации, а также по транспортным средствам подразделений с отдельной регистрацией в налоговом органе, у которых заполнено значение Аппарата акима.

Приложение заполняется по всем основным средствам, являющимся объектами обложения налогом на транспорт в течение отчетного периода.
Информация об обложении транспортного средства налогом устанавливается документом Регистрация транспортных средств.

Для автоматического распределения объектов транспортного налога между аппаратами акимов, в карточке организации таких подразделений требуется установить признак Относить налоги к бюджету городов районного значения, сел, поселков, сельских округов на закладке Учетная политика и налоги.

Приложение заполняется по всем основным средствам, являющимся объектами обложения земельным налогом в течение отчетного периода.
Информация об обложении транспортного средства налогом устанавливается документом Регистрация земельных участков.
