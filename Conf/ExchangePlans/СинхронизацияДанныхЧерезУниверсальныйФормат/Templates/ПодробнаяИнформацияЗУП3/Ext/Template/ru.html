Совместное использование конфигураций
1С:ERP Управление предприятием 2 для Казахстана, редакция 2.4 и Зарплата и управление персоналом для Казахстана, редакция 3.1

Цели совместного использования

Поддержка совместного использования конфигурации Зарплата и управление персоналом для Казахстана, ред. 3.1 и 1С:ERP Управление предприятием 2 для Казахстана, ред. 2.4: разделение зарплатного и финансового контуров учета, ограничение доступа к конфиденциальной кадровой и зарплатной информации, а также обеспечение независимости конфигураций.

Обеспечение синхронности нормативно-справочной информации.

Выгрузка из конфигурации Зарплата и управление персоналом для Казахстана, ред. 3.1 для целей финансового учета и контроллинга данных по отражению начисленной зарплаты в бухучете, начисленных оценочных обязательств по отпускам. Планирование в 1С:ERP Управление предприятием 2 для Казахстана, ред. 2.4 операций по выплате зарплаты посредством использования заявок на расходование денежных средств

Общая информация

Обмен данными между конфигурациями двусторонний, производится на уровне документов и справочной информации из конфигурации Зарплата и управление персоналом для Казахстана, ред. 3.1 в конфигурацию 1С:ERP Управление предприятием 2 для Казахстана, ред. 2.4.

Документы и справочная информация могут создаваться в конфигурации Зарплата и управление персоналом для Казахстана, ред. 3.1 и мигрировать в конфигурацию 1С:ERP Управление предприятием 2 для Казахстана, ред. 2.4. При переносе данных из конфигурации Зарплата и управление персоналом для Казахстана, ред. 3.1 в 1С:ERP Управление предприятием 2 для Казахстана, ред. 2.4. необходимо обеспечить распределение затрат на регламентированную зарплату, налоги и взносы по счетам бухгалтерского и налогового учета и объектам аналитического учета. Затраты распределяются там же, где рассчитываются, то есть в конфигурации Зарплата и управление персоналом для Казахстана, ред. 3.1.

Для совместного использования Зарплата и управление персоналом для Казахстана, ред. 3.1 и 1С:ERP Управление предприятием 2 для Казахстана, ред. 2.4 и синхронизации данных между ними в обеих системах должна быть активна опция «Использовать синхронизацию данных»; в 1С:ERP Управление предприятием 2 для Казахстана, ред. 2.4 отключена опция «Использовать начисление зарплаты».

Для использования сценария «Выплата зарплаты» должна быть включена опция «Использовать заявки на расходование денежных средств», если выключена, то ведомости на выплату зарплаты из Зарплата и управление персоналом для Казахстана, ред. 3.1 выгружаются, заявки на расходование денежных средств (выплата зарплаты) в 1С:ERP Управление предприятием 2 для Казахстана, ред. 2.4 не создаются.

Отражение зарплаты в финансовом учете

Документы идентифицируются по уникальным идентификаторам. При этом соблюдается необходимая целостность данных. 

Принципы регистрации изменений

 Принцип регистрации "При необходимости"

Проверка необходимости регистрации изменений и выгрузки объектов при обмене происходит в соответствии с логикой для режима выгрузки "Выгружать при необходимости". В данном режиме регистрация изменений и выгрузка объектов происходит без использования фильтров и отборов, определенных в правилах регистрации объектов, но с контролем ссылочной целостности. Если объект не выгружался в составе других объектов обмена "по ссылке", то регистрация изменений для него производиться не будет. В противном случае, все изменения объекта будут регистрироваться к обмену.

Принцип регистрации "Режим выгрузки справочников"

Проверка необходимости регистрации изменений и выгрузки объектов при обмене происходит в соответствии с правилом отправки нормативно-справочной информации, заданным в настройках синхронизации  

  • Отправлять всю - используется проверка согласно логике для режима выгрузки "Выгружать по условию". В данном режиме регистрация изменений и выгрузка объектов происходит с использованием фильтров и отборов, определенных в правилах регистрации объектов.
  • Отправлять только используемую в документах - используется проверка согласно логике для режима выгрузки "Выгружать при необходимости".
  • Не отправлять - используется проверка согласно логике для режима выгрузки "Не выгружать". В этом режиме изменения объектов не регистрируются автоматически (через подписки на события) и не выгружаются, даже если регистрация изменений была произведена пользователем вручную.

Принцип регистрации "Режим выгрузки документов"

Проверка необходимости регистрации изменений и выгрузки объектов при обмене происходит в соответствии с правилом отправки документов, заданным в настройках синхронизации

  • Отправлять все, начиная с даты ... - используется проверка согласно логике для режима выгрузки "Выгружать по условию". В данном режиме регистрация изменений и выгрузка объектов происходит с использованием фильтров и отборов, определенных в правилах регистрации объектов. Дата начала выгрузки документов используется как параметр плана обмена в отборах.
  • Ручная синхронизация данных - используется проверка согласно логике для режима выгрузки "Выгружать вручную". В этом режиме изменения объектов не регистрируются автоматически (через подписки на события); объекты регистрируются к выгрузке вручную пользователем и выгружаются только если соответствуют фильтрам и отборам, определенным в правилах регистрации объектов.
  • Не отправлять - используется проверка согласно логике для режима выгрузки "Не выгружать". В этом режиме изменения объектов не регистрируются автоматически (через подписки на события) и не выгружаются, даже если регистрация изменений была произведена пользователем вручную.

Особенности синхронизации документов

Для выгрузки данных с детализацией по физическим лицам, необходимо в узле обмена конфигурации ЗУП установить флаг Выгружать с детализацией по физическим лицам.

Отражение зарплаты в бух. учете

Документ в ЗУП: Отражение зарплаты в бух. учете
Документ в УПК: Отражение зарплаты в фин. учете

Цель: отражение в финансовом учете данных по расходам на оплату труда.

При выгрузке из ЗУП в УПК данные документа Отражение зарплаты в бух. учете переносятся полностью. При загрузке в УПК документа  Отражение зарплаты в бух. учете  создается документ Отражение зарплаты в финансовом учете.

Перечисление взносов и отчислений

Документ в ЗУП: Ведомость на перечисление взносов, отчислений
Документ в УПК: Заявка на расходование денежных средств

Документ Ведомость на перечисление взносов, отчислений  включает в себя одну или несколько Ведомостей на перечисление взносов и отчислений.

При загрузке в УПК документа Ведомость на перечисление взносов, отчислений создается документ Заявка на расходование денежных средств с видом операции "Перечисление налога" и признаком перечисление в бюджет. Также создается одна или несколько, в зависимости от состава табличной части документа-источника, ведомостей на перечисление.

Сумма Заявки на расходование денежных средств соответствует итоговой сумме "К выплате" по всем ведомостям, входящим в Ведомость на перечисление взносов, отчислений .

Ведомость в банк

Документ в ЗУП: Ведомость в банк
Документ в УПК: Заявка на расходование денежных средств

При загрузке в УПК документа Ведомость в банк создается документ Заявка на расходование денежных средств с видом операции "Выплата зарплаты" и видом выплаты "По зарплатному проекту". 

Сумма Заявки на расходование денежных средств соответствует итоговой сумме документа Ведомость в банк.

При загрузке в ЗУП Выработки сотрудников создается документ Данные для расчета зарплаты с видом операции "Сдельные работы".
