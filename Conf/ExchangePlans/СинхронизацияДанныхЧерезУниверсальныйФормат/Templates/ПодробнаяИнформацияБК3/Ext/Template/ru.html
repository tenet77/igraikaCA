Общая информация

Синхронизация данных производится на уровне документов и справочной информации.

Синхронизация данных производится в двустороннем порядке.

Процесс обмена данными осуществляется за счет передачи информации между программами в виде текстовых сообщений, содержащих данные в формате Enterprise Data, одним из следующих способов, задаваемых на этапе настройки новой синхронизации:

  • через локальный или сетевой каталог;
  • через FTP-ресурс;
  • по электронной почте.

Для передачи информации в качестве контейнера сообщения обмена выступают XML-файлы.

Процесс создания новой синхронизации данных включает в себя последовательное выполнение настроек для каждой из баз-участников обмена, и может начинаться как на стороне БК, так и на стороне ЗУП.

Принципы регистрации изменений

Принцип регистрации "При необходимости"
Проверка необходимости регистрации изменений и выгрузки объектов при обмене происходит в соответствии с логикой для режима выгрузки "Выгружать при необходимости". В данном режиме регистрация изменений и выгрузка объектов происходит без использования фильтров и отборов, определенных в правилах регистрации объектов, но с контролем ссылочной целостности. Если объект не выгружался в составе других объектов обмена "по ссылке", то регистрация изменений для него производиться не будет. В противном случае, все изменения объекта будут регистрироваться к обмену.
Принцип регистрации "Режим выгрузки справочников"
Проверка необходимости регистрации изменений и выгрузки объектов при обмене происходит в соответствии с правилом отправки нормативно-справочной информации, заданным в настройках синхронизации
  • Отправлять всю - используется проверка согласно логике для режима выгрузки "Выгружать по условию". В данном режиме регистрация изменений и выгрузка объектов происходит с использованием фильтров и отборов, определенных в правилах регистрации объектов.
  • Отправлять только используемую в документах - используется проверка согласно логике для режима выгрузки "Выгружать при необходимости".
  • Не отправлять - используется проверка согласно логике для режима выгрузки "Не выгружать". В этом режиме изменения объектов не регистрируются автоматически (через подписки на события) и не выгружаются, даже если регистрация изменений была произведена пользователем вручную.
Принцип регистрации "Режим выгрузки документов"
Проверка необходимости регистрации изменений и выгрузки объектов при обмене происходит в соответствии с правилом отправки документов, заданным в настройках синхронизации
  • Отправлять все, начиная с даты ... - используется проверка согласно логике для режима выгрузки "Выгружать по условию". В данном режиме регистрация изменений и выгрузка объектов происходит с использованием фильтров и отборов, определенных в правилах регистрации объектов. Дата начала выгрузки документов используется как параметр плана обмена в отборах.
  • Ручная синхронизация данных - используется проверка согласно логике для режима выгрузки "Выгружать вручную". В этом режиме изменения объектов не регистрируются автоматически (через подписки на события); объекты регистрируются к выгрузке вручную пользователем и выгружаются только если соответствуют фильтрам и отборам, определенным в правилах регистрации объектов.
  • Не отправлять - используется проверка согласно логике для режима выгрузки "Не выгружать". В этом режиме изменения объектов не регистрируются автоматически (через подписки на события) и не выгружаются, даже если регистрация изменений была произведена пользователем вручную.

Особенности синхронизации документов

Для выгрузки данных с детализацией по физическим лицам, необходимо в узле обмена конфигурации ЗУП установить флаг Выгружать с детализацией по физическим лицам.

Отражение зарплаты в бух. учете

Документ в ЗУП: Отражение зарплаты в бух. учете
Документ в БК: Отражение зарплаты в бух. учете (Интеграция с ЗУП 3.0)

Документ Отражение зарплаты в бух.учете мигрирует между БК и ЗУП в двустороннем порядке.

При выгрузке из ЗУП в БК данные документа Отражение зарплаты в бух. учете переносятся полностью.

При выгрузке из БК в ЗУП документа Отражение зарплаты в бух. учете переносятся только реквизиты - Зарплата отражена в бух.учете и Бухгалтер, для корректного ведения учета в ЗУП.

Платежное поручение

Документ в ЗУП: Платежное поручение
Документ в БК: Платежное поручение (исходящее)

Документ Платежное поручение в ЗУП включает в себя одну или несколько Ведомостей в банк. Отдельно Ведомость в банк не выгружается в БК.

При загрузке в БК документа Платежного поручения создается документ Платежное поручение (исходящее) с видом операции "Перечисление заработной платы". Также создается одна или несколько, в зависимости от состава табличной части документа-источника, ведомостей Зарплата к выплате организаций - через банк.

Сумма Платежного поручения (исходящего) соответствует итоговой сумме "К выплате" по всем ведомостям, входящим в Платежное поручение.

Ведомость в кассу

Документ в ЗУП: Ведомость в кассу
Документ в БК: Расходный кассовый ордер

При загрузке в БК документа Ведомость в кассу создается документ Расходный кассовый ордер с видом операции "Выплата заработной платы по ведомостям". Также создается ведомость "Зарплата к выплате организаций" - через кассу.

Сумма Расходного кассового ордера соответствует итоговой сумме "К выплате" Ведомости в кассу.

Ведомость на выплату зарплаты через раздатчика

Документ в ЗУП: Ведомость на выплату зарплаты раздатчиком
Документ в БК: Авансовый отчет

При загрузке в БК документа Ведомость на выплату через раздатчика создается документ Авансовый отчет . Также создается ведомость "Зарплата к выплате организаций" - через кассу.

Сумма Авансового отчета  соответствует итоговой сумме "К выплате" Ведомости на выплату через раздатчика.

Перечисление взносов и отчислений

Документ в ЗУП: Перечисление взносов и отчислений
Документ в БК: Платежное поручение (исходящее)

Документ Перечисление взносов и отчислений в ЗУП включает в себя одну или несколько Ведомостей на перечисление взносов и отчислений. Отдельно Ведомость на перечисление взносов и отчислений не выгружается в БК.

При загрузке в БК документа Перечисление взносов и отчислений создается документ Платежное поручение (исходящее) с видом операции "Перечисление социальных отчислений" / "Перечисление пенсионных взносов". Также создается одна или несколько, в зависимости от состава табличной части документа-источника, ведомостей СО перечисление в фонды / ОПВ перечисление в фонды.

Сумма Платежного поручения (исходящего) соответствует итоговой сумме "К выплате" по всем ведомостям, входящим в Перечисление взносов и отчислений .

Возврат сотрудником задолженности

Документ в ЗУП: Возврат сотрудником задолженности
Документ в БК: Приходный кассовый ордер

При загрузке в БК документа Возврат сотрудником задолженности создается документ Приходный кассовый ордер с видом операции "Возврат денежных средств сотрудником".

Сумма Приходного кассового ордера соответствует итоговой сумме документа Возврат сотрудником задолженности.

Сведения о незачисленной зарплате

Документ в ЗУП: Сведения о незачисленной зарплате
Документ в БК: Платежное поручение (входящее)

Документ Сведения о незачиселнной зарплате в ЗУП включает в себя список сотрудников по одной Ведомости в банк. Отдельно Ведомость в банк не выгружается в БК.

При загрузке в БК документа Сведения о незачисленной зарплате создается документ Платежное поручение (входящее) с видом операции "Возврат заработной платы". Также создается ведомость Возврат зарплаты сотрудников организации.

Сумма Платежного поручения (входящего) соответствует итоговой сумме по списку сотрудников, входящих в Сведения о незачисленной зарплате.

Сведения о незачисленных взносах, отчислениях

Документ в ЗУП: Сведения о незачисленных взносах, отчислениях
Документ в БК: Платежное поручение (входящее)

Документ Сведения о незачисленных взносах, отчислениях в ЗУП включает в себя список сотрудников по одной Ведомости на перечисление взносов, отчислений. Отдельно Ведомость на перечисление взносов, отчислений не выгружается в БК.

При загрузке в БК документа Сведения о незачисленных взносах, отчислениях создается документ Платежное поручение (входящее) с видом операции "Возврат взносов и отчислений соц. страхования" / "Возврат пенсионных взносов". Также, в зависимости от состава табличной части документа-источника, создается ведомость "Социальное страхование возврат из фондов" / "Пенсионные взносы возврат из фондов".

Сумма Платежного поручения (входящего) соответствует итоговой сумме по списку сотрудников, входящих в Сведения о незачисленных взносах, отчислениях.

Ограничения

Документ Ведомость на выплату перечислением не передается в конфигурацию БК
