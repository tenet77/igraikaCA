Правила распределения расходов

Справочник предназначен для регистрации и настройки правил распределения материалов и работ, а также статей расходов по подразделениям и партиям производства.

При распределении учитывается заданное значение показателя.

Справочник предназначен для регистрации и настройки правил распределения материалов и работ, а также статей расходов по подразделениям и выпускам без распоряжения.

  • Сумма материальных затрат, сумма затрат на оплату труда. Значения показателей рассчитываются автоматически.
  • Вводится вручную при изменении. Значения показателей вводятся пользователем вручную. Список значений вводится в отдельной форме при нажатии на гиперссылку Значения. Показатели вводятся при необходимости в случае изменения значения показателя.
  • Вводится вручную ежемесячно. Значения показателей вводятся пользователем вручную. Список значений вводится в отдельной форме при нажатии на гиперссылку Значения. Значения показателей необходимо вводить ежемесячно.

Пример. Распределение расходов по подразделениям пропорционально объему потребленой электроэнергии подразделениями предприятия. Информация об объеме потребленной электроэнергии вводится ежемесячно. Для этого необходимо создать показатель для распределения расходов по подразделениям Объем потребленной электроэнергии, для которого установить, что он Вводится вручную ежемесячно. Таким образом, появляется возможность ежемесячно распределять расходы в соответствии с введенным текущим значением показателя.
